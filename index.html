Cara Kerja API Key
API Key digunakan oleh website/aplikasi lain (Web B) untuk mengirim request ke server ini (Web A). Setiap request yang menggunakan API Key akan mengurangi limit Anda. Terdapat 3 tipe API Key: Reaction, Downloader, dan HD Image.
